## UI v2 — four switchable looks, persistent shell, dashboard, liquidity dashboard with an SVG chart

Plan: `docs/plans/2026-09-05-ui-v2-plan.md` · progress: `docs/plans/2026-09-05-ui-v2-progress.md` · quality: `docs/ui-overhaul/v2-quality-snapshot.md`

### What changes for the user
- **Four looks, light and dark each**, chosen in Settings → Appearance (topbar gear, sidebar gear, or ⌘K): Obsidian Terminal, Aurora Glass, Neo-Brutal Fintech, Quiet Luxury. Default: Quiet Luxury, dark. Choices persist **per browser** (`localStorage`; no accounts, nothing sent to the backend), painted before the first frame.
- **Persistent shell**: collapsible sidebar with a sliding indicator, topbar with the page title, ⌘K command palette (navigation, looks, modes, settings), connection status, six-route bottom bar on phones, skip link, one `<main>`.
- **Dashboard** replaces the landing page (greeting, portfolio strip in a height-reserved slot, tool tiles with live counts, resource chips).
- **Analyze**: two-column workspace with a sticky summary rail.
- **Deal boards**: glass toolbars, stage rows on surface tiers, compact empty rows, token stage accents, icon deal-type badges, labelled substage checkboxes, Add Deal labelled at every width.
- **Liquidity**: a grid dashboard — four KPIs, an **SVG timeline chart** (virtualised, theme-reactive, same keyboard/pointer contract), day detail, and an overview sidebar that is reachable on phones.
- **Motion**: presets and directives read each look's tempo; command palette and drawer choreographies; sparkline and balance-line draw-on; count-ups; every entrance within 500 ms; ambient effects in CSS.
- REPS is untouched apart from mounting inside the shell.

### What does not change
- **No backend change.** `BackEnd/**` and `frontend/src/{stores,api,utils,router,types,config}` are byte-identical to `ui-baseline` (gates G1/G2).
- **Same requests, same payloads, same dialog copy.** No network golden changed in v2. Every `data-testid` the e2e suite references still exists (unit-tested).
